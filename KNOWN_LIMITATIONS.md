# Known limitations

- Visible source declarations can be false, omit shared origins or support multiple interpretations; EIM does not authenticate provenance or determine claim truth.
- Only2–4 permitted short UTF-8 text files: HTTPS raw.githubusercontent.com or legal one-label GitHub Pages owners; .txt/.md/.adoc/.sol; no queries, fragments, credentials or recursive crawling. Body32768bytes, normalized text8000codepoints.
- UNKNOWN reflects insufficient visible provenance/relevance, never a temporary fetch/model failure fallback. DEPENDENT is non-transitive. The maximum set is pairwise supported, not a count of hidden original evidence families.
- Semantic interpretation is nondeterministic. Some real requests have MAJORITY_DISAGREE and create no Assessment. Finite successful examples do not guarantee liveness, accuracy or prompt-injection immunity.
- Stable Studionet is a hosted test environment. Actual exposed participant identities do not prove independent operators or model-provider diversity. Private Validator verdicts are not generally exposed.
- Real-model negative controls are **NOT REAL-NETWORK VERIFIED**.277 local contract tests use scripted HTTP/model boundaries; they prove guards/control flow, not universal model rejection reliability.
